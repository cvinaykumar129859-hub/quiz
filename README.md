# QuizMaster

A full-stack quiz platform built with React, TypeScript, Express, and MongoDB. Quiz answers are stored only on the API and are returned only after a submission is scored server-side.

## Requirements

- Node.js 20 or newer and npm
- MongoDB Atlas connection string (or a local MongoDB instance)

## Setup

1. Install dependencies from the repository root: `npm install`
2. Copy `backend/.env.example` to `backend/.env` and set `MONGODB_URI` and a long random `JWT_SECRET`.
3. Set `FRONTEND_ORIGIN=http://localhost:5173` in `backend/.env` for local development.
4. Copy `frontend/.env.example` to `frontend/.env` if the API is not at `http://localhost:4000/api`.
5. Seed the database: `npm run seed`
6. Start the frontend and API together: `npm run dev`
7. Open `http://localhost:5173`.

The API connects to the `quizmaster_db` database. The seed command idempotently creates 24 quizzes (8 categories x 3 difficulty levels) containing 240 questions total. It requires a working MongoDB connection.

## Scripts

- `npm run dev` starts the Vite frontend and Express API concurrently.
- `npm run build` typechecks and builds both workspaces.
- `npm run seed` initializes or refreshes the seeded quiz catalog.

## Deploying

For a Render API service, leave the root directory blank, use `npm install && npm run build` as the build command, and `npm start` as the start command. Set `NODE_ENV=production`, `MONGODB_URI`, `JWT_SECRET`, and `FRONTEND_ORIGIN` in the Render environment. Set `FRONTEND_ORIGIN` to the exact Vercel origin, for example `https://quiz-blond-eight-35.vercel.app` (no trailing slash). Multiple allowed origins can be comma-separated.

In Vercel, set `VITE_API_URL` to the Render API URL followed by `/api`. Production auth cookies use `SameSite=None; Secure` so the Vercel frontend can authenticate against the separate Render origin. Use HTTPS for both services.

## Security notes

Authentication uses an HTTP-only JWT cookie, bcrypt password hashes, Zod request validation, and rate-limited login/registration endpoints. The API restricts CORS to `FRONTEND_ORIGIN`. Never commit `.env` files or publish Atlas credentials. For production, configure HTTPS, the production frontend origin, and a strong unique JWT secret.

Quiz selection data omits correct answers and explanations. Submission accepts selected option indexes only; score and review data are generated by the API. Result reads are scoped to the signed-in user.
